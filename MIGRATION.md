## Почему переезд ничего не сломал

- **Абсолютных путей в проекте нет.** Ни в данных, ни в разметке, ни в документации — проверено
  поиском по `C:\` и по старому пути.
- **Инструменты вычисляют корень от собственного расположения** (`ROOT` из `import.meta.url`),
  поэтому им всё равно, где лежит папка.
- **Страницы ссылаются только на относительные пути** (`Screens/…`, `pages/…`, `assets/…`),
  внешних запросов нет — сайт открывается двойным кликом по `index.html`.
- **Chrome ищется по списку кандидатов** и переменной `CHROME_PATH`, а не по жёсткому пути проекта.
- **Кириллица в имени папки больше не встречается:** новый путь латинский, что удобнее для команд
  и для git.

## Если понадобится перенести ещё раз

1. Скопировать всё, кроме `.tmp/`, в новую папку.
2. В новой папке: `node tools/doctor.mjs` — покажет, все ли файлы на месте.
3. `node tools/build.mjs` — пересобрать страницы (заодно проверка, что путь определился верно).
4. `node tools/validate.mjs` — должно быть 0 ошибок.
5. Сверить контрольные числа выше; при памяти ≥ 4 ГБ прогнать `node tools/check-widths.mjs 1280,1440,1920`.
6. Удалить `.tmp/`, если он появился, и обновить путь в `AGENTS.md` и в этом файле.
