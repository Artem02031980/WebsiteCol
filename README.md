# Коллекция сайтов

Личный каталог понравившихся сайтов: главная страница с поиском, фильтрами и карточками
и отдельная страница-разбор на каждый сайт. Чемпионата больше нет — сайты не соревнуются,
их разбирают: что это, чем интересен, кто и на чём сделал.

Всё статическое: открывается двойным кликом по `index.html` с диска, без сервера, сборщиков,
npm-зависимостей и внешних запросов. Нужен только Node, чтобы пересобрать страницы после правки данных.

Дизайн: светлая тема, лаконичный интерфейс, логотип в шапке и в «герое» каталога.
Сайт **адаптивный**: от 360 px телефона до широких десктопов, без горизонтальной прокрутки.

## Как открыть

1. `index.html` — каталог: поиск, сортировка, свёрнутые фильтры, виды «Карточки» и «Список».
2. `pages/001-weeksync.html` (и так далее) — страница-разбор каждого сайта: что это, чем интересен,
   паспорт, палитра, технические факты, технологии с доказательствами.

По умолчанию коллекция отсортирована «по номеру с конца» — свежие сайты сверху.
Состояние поиска, фильтров и сортировки попадает в адрес: такой ссылкой можно делиться.

## Состав

```
index.html                                генерируется, руками не правим
pages/                                    страница на каждый сайт (генерируется)
Screens/                                  скриншоты: 001.webp, 002.webp, …
data/sites.json                           все сайты и их параметры — источник правды
data/taxonomy.json                        справочники категорий, стилей, приёмов, языков
data/palette.json                         палитры, измеренные из скриншотов (генерируется)
data/SCHEMA.md                            описание всех полей
assets/style.css                          токены и вёрстка: светлая тема, адаптивность
assets/app.js                             поиск, фильтры, сортировка, состояние в адресе
assets/logo.svg, assets/favicon.svg       логотип и иконка
tools/build.mjs                           data/*.json → страницы
tools/add-site.mjs                        добавить черновик новой записи
tools/palette.mjs                         извлечь палитры и размеры из Screens/
tools/validate.mjs                        проверки: данные, разметка, доступность, контраст
tools/check-widths.mjs                    горизонтальное переполнение на 360–1920 px
tools/doctor.mjs                          самопроверка окружения и целостности проекта
AGENTS.md                                 правила проекта для агента
STATE.md                                  снимок состояния и открытые вопросы
RESEARCH_PROMPT.md                        шаблон задания на разбор нового сайта
```

## Пополнить коллекцию

1. Снять скриншот главной страницы (десктоп, ширина от 1280 px) и положить в `Screens/`
   с номером = текущий максимум + 1: `032.webp`. Скриншоты снимает владелец — автоматическая
   съёмка не делается.
2. `node tools/add-site.mjs <url> --slot 032 --name "Название"` — создать каркас записи.
3. Разобрать сайт субагентом по шаблону `RESEARCH_PROMPT.md` (один агент на сайт, можно
   несколько параллельно) и заполнить запись в `data/sites.json` по `data/SCHEMA.md`.
   Поля, для которых данных нет, остаются пустыми — страница честно покажет заглушку.
4. `node tools/build.mjs` — пересобрать страницы.
5. `node tools/validate.mjs` — до нуля ошибок и предупреждений.
6. `node tools/palette.mjs` — обновить палитры, если добавились скриншоты (нужно ≥ 4 ГБ памяти);
   `node tools/check-widths.mjs` — убедиться, что переполнения нет.
7. Обновить `STATE.md` и закоммитить партию.

## Проверки

`node tools/validate.mjs` проверяет: состав файлов (включая отсутствие устаревших файлов
чемпионата), ссылочную целостность данных, разметку всех страниц (один h1, alt и размеры картинок,
локальные ссылки, skip-link, логотип на каждой странице), доступность в CSS (`:focus-visible`,
`prefers-reduced-motion`, `overflow-x`, адаптивные breakpoint-ы), контраст пар токенов по WCAG
и наличие незаполненных полей.

`node tools/check-widths.mjs` грузит каждую страницу в iframe шириной 360, 768, 1024, 1280, 1440
и 1920 px и измеряет горизонтальное переполнение. Свои ширины — аргументом:
`node tools/check-widths.mjs 390,1280`.

## Документы проекта

| Файл | Для кого |
|---|---|
| `AGENTS.md` | агент: правила, инварианты, команды, ритуал добавления сайта, гигиена ресурсов |
| `STATE.md` | агент и владелец: что уже собрано, открытые вопросы |
| `RESEARCH_PROMPT.md` | агент: шаблон задания на разбор нового сайта |
| `data/SCHEMA.md` | агент: все поля данных и правила их заполнения |

## Чего здесь намеренно нет

- **Чемпионата.** Баллов, номинаций, рейтингов и страниц соревнования нет ни в данных, ни на страницах.
- **Выдуманных данных.** Если факт не измерен или не подтверждён — стоит `null`, а на странице
  `<span class="placeholder">не указано</span>`. Пустые поля так и остаются пустыми до проверки.
- **Проверок ссылок «на всякий случай».** Состояние ссылок проверяется только по прямой команде
  владельца; фильтр «Состояние ссылки» на главной появляется сам, когда в коллекции находятся
  неживые ссылки.
