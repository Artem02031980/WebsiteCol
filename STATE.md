## Открытые вопросы

1. **Языки мультиязычных сайтов.** 019 ScreenTune, 023 Franklin Azzi и 031 Clay пока помечены
   только как `multi` — конкретных языков в разборе не было. Если появятся данные, дополнить
   `facts.languages` конкретными id (как у 028).
2. **022 Orbify** — единственная запись без описания владельца: сайт добавлен только ссылкой.
   Если владелец сформулирует, чем сайт зацепил, — дописать в `description_user`.
3. **024 xAI** — сайт закрыт Cloudflare для этой сети: данные добыты через релеи и сканеры.
   Перепроверить, если появится доступ (теперь это записывается в `observations`).
4. **027 Marble** — скриншот зафиксировал более раннюю версию: формы ожидания на живом сайте уже нет.
5. **012 Prand** — сайт недоступен из этой сети, данные получены через релеи; при возможности
   перепроверить напрямую.
6. **Состояние ссылок.** Все 31 сайт помечены как «Сайт жив», проверки не было с момента редизайна.
   Фильтр «Состояние ссылки» на главной появится сам, когда при проверке (только по команде
   владельца) найдутся неживые ссылки.
7. **Исследования без браузера.** У партий 018–031 браузер не запускался (мало памяти), поэтому
   поведение анимаций описано по коду. Если владелец захочет живую проверку — запускать точечно,
   по одному сайту, при памяти ≥ 4 ГБ.

## Чего в проекте намеренно нет

Выдуманных данных (не измерено — `null` и заглушка на странице), чемпионата (баллов, номинаций,
рейтингов), внешних запросов и зависимостей (npm-пакетов нет вовсе), аналитики и серверной части —
только статические файлы на диске. Проверок ссылок «на всякий случай» тоже нет: только по команде
владельца.
