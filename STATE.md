## Открытые вопросы

1. **Языки мультиязычных сайтов.** 019 ScreenTune, 023 Franklin Azzi и 031 Clay пока помечены
   только как `multi` — конкретных языков в разборе не было. Если появятся данные, дополнить
   `facts.languages` конкретными id (как у 028).
2. **022 Orbify** — запись без описания владельца: сайт добавлен только ссылкой.
   Если владелец сформулирует, чем сайт зацепил, — дописать в `description_user`.
3. **024 xAI** — сайт закрыт Cloudflare для этой сети: данные добыты через релеи и сканеры.
   Перепроверить, если появится доступ.
4. **027 Marble** — скриншот зафиксировал более раннюю версию: формы ожидания на живом сайте уже нет.
5. **012 Prand** — сайт недоступен из этой сети, данные получены через релеи; при возможности
   перепроверить напрямую.
6. **Состояние ссылок.** Все 41 сайт помечены как «Сайт жив», полной проверки не было.
   Фильтр «Состояние ссылки» появится сам, когда при проверке (только по команде владельца)
   найдутся неживые ссылки.
7. **Исследования без браузера.** У партий 018–031 браузер не запускался (мало памяти), поэтому
   поведение анимаций описано по коду. Если нужна живая проверка — точечно, по одному сайту,
   при памяти ≥ 4 ГБ.
8. **032 Fernand** — главная отвечает 200, но тело отдаётся очень медленно; страна, автор
   и контакты не прочитаны. Дозаполнить, если нужен полный паспорт.
9. **041 Lightspark** — support.lightspark.com не разрешается по DNS; ссылка в подвале
   отмечена битой. Если починят — убрать из `facts.links.broken`.
