# Font Awesome 5 Free

Локальная копия шрифтов Font Awesome Free 5.15.3 (desktop, OTF).

- `fa-brands-400.otf` — бренды;
- `fa-regular-400.otf` — обычные иконки;
- `fa-solid-900.otf` — заливные иконки;
- `LICENSE.txt` — лицензии Font Awesome Free (шрифты — SIL OFL 1.1).

Подключение и классы иконок — в `assets/fontawesome.css`. Источник: `C:\Fonts\fontawesome-free-5.15.3-desktop\otfs`.
