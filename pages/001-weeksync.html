Что это

Одностраничный лендинг планировщика для творческих команд, где работа планируется неделями: 5 долларов за пользователя в месяц, есть подключение AI-агента. Сделан как отрывной билет — пунктирная перфорация нарисована CSS-рамкой, разрез имитируют два SVG-лезвия ножниц, а прокрутка реализована не нативно, а трансформом внутри фиксированного контейнера высотой 100vh. Технически это Next.js (App Router) с CSS-модулями, самохостингом Inter и Red Hat Mono, Google Analytics 4 и Cloudflare перед origin на DigitalOcean App Platform.

Описание владельца коллекции: Забавный минималистичный сайт планировщика для команд. Стилизован под отрывной билет, который разрезается при скролле.

Чем интересен

  • Метаданные отдаются стримом в конце документа, а og:*, twitter:* и canonical отсутствуют полностью: превью в соцсетях формировать нечем, зато есть meta keywords.
  • Страница прокручивается не нативно: контейнер фиксирован (100vh, overflow: hidden), содержимое двигается трансформом, у body отключён скролл; на ширине 1023 px и меньше всё превращается в обычный поток документа.
  • Отрывной билет собран без единой картинки: перфорация — это пунктирная CSS-рамка, разрез имитируют два SVG-лезвия ножниц с поворотом на ±20 градусов и отдельная «молния».
  • Заголовок и счётчики «N of 3» скрыты до выполнения JS (opacity: 0, печать посимвольно), поэтому без JavaScript пользователь видит пустые блоки; cookie-баннер тоже рендерится только на клиенте.
  • Тяжёлых библиотек нет: ноль совпадений gsap, three, lottie, framer-motion и tailwind; анимация собрана из CSS-модулей и PNG-спрайта на 29 кадров, звук — из двух коротких MP3.

Обоснования по разделам

Юзабилити и UX
Меню из четырёх пунктов свёрстано как div без ссылок, заголовок и счётчики скрыты до JS, prefers-reduced-motion не обрабатывается — при этом сам интерфейс чистый и понятный.
Дизайн и визуальное восприятие
Метафора отрывного билета выдержана до деталей: перфорация, корешок, ножницы, фигурные скобки у кнопок; бежево-жёлто-зелёная палитра спокойная.
Контент
Три карточки фич, цена, два живых отзыва с ролями, девять вопросов FAQ; автора и команды на сайте нет.
Техническое качество
HTTPS, живой стек Next.js App Router без тяжёлых библиотек, 14 ссылок без битых; SEO-обвязка провалена: нет og-тегов, sitemap, robots и canonical, title дублирует description.
Функциональность и интерактивность
Аккордеон FAQ, карусель отзывов, звуки на 34 элементах, печать текста, разрез билета; формы обратной связи и поиска нет.
Доверие и репутация
Правовые страницы есть и обновлялись в 2026 году, отзывы подписаны именами и должностями; юрлицо, адрес и автор не раскрыты.
Инновации и технологичность
Работа с трансформом вместо нативной прокрутки, PNG-спрайт вместо видео и звук через Web Audio API без библиотек.
Соответствие категории и целям
Для лендинга планировщика закрыто главное: что это, сколько стоит, что говорят пользователи, частые вопросы.

Что не проверено

  • Итоговый вид после гидратации JS не проверялся: единственный визуальный источник — скриншот 001.webp.
  • Вес страницы, Core Web Vitals и число запросов не измерялись.
  • Мобильное поведение не проверялось: известны только медиазапросы (max-width: 1023px и 479px) и то, что на узких экранах loop-scroll отключается.
  • Ссылки на Telegram и X подтвердить не удалось: соединение из этой среды не устанавливается — это ограничение сети, а не доказательство битой ссылки.
  • Аномалия отдачи: без заголовка Accept-Encoding сервер отдаёт около 24,8 КБ и соединение зависает; полный документ (53 642 байта) приходит только сжатым. Причина не установлена.
  • Назначение компонента Wheel (четыре rotateContainer с mix-blend-mode) не определено: в серверной разметке внутри нет ни картинок, ни видео.
  • prefers-reduced-motion не обрабатывается ни в CSS, ни в JS — при этом на странице есть звук, след курсора и печать текста.
  • Полный список страниц неизвестен (sitemap отсутствует): достоверно существуют /, /login и три правовые страницы; /pricing, /faq, /reviews и /about отдают 404.
  • Ссылки меню («Problems It Solves», «Pricing», «Reviews», «FAQ») свёрстаны как div без href — для поисковых роботов внутренней навигации в меню нет.

Технологии с доказательствами

  • React 19 (стриминг метаданных) — title и description приходят не в <head>, а в конце <body> и завершаются маркером self.__next_f.push([1,"d:\"$8:metadata\""])
  • CSS Modules — хешированные классы ticket_ticket__d_kvJ, FeatureCard_wrapper__qwb3w; в 37 735 символах CSS ноль совпадений tailwind и --tw-
  • next/font, самохостинг шрифтов — @font-face с src /_next/static/media/*.woff2: 7 начертаний Inter и 8 Red Hat Mono, preload в заголовках
  • next/image — <img data-nimg="1" src="/_next/image?url=…&w=1920&q=75"> с srcSet
  • Embla Carousel — классы Reviews_embla__9yLXa и девять упоминаний embla в JS-бандле
  • Web Audio API — createBufferSource и decodeAudioData, файлы /landing/hover.mp3 (972 Б) и /landing/click.mp3 (5 374 Б)
  • Google Analytics 4 — googletagmanager.com/gtag/js?id=G-M53918BGEB и gtag('config', 'G-M53918BGEB')
  • Cloudflare — заголовки Server: cloudflare, CF-RAY, cookie __cf_bm, обфускация почты через /cdn-cgi/l/email-protection
  • DigitalOcean App Platform — заголовки x-do-app-origin и x-do-orig-status: 200
