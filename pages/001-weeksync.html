Что это

Одностраничный лендинг планировщика для творческих команд: работа расписывается неделями, а проекты, загрузка и личные цели собраны в одном месте. Сайт сделан как отрывной билет с перфорацией и разрезом ножницами, который раскрывается по мере прокрутки. Забавный минималистичный сайт планировщика для команд. Стилизован под отрывной билет, который разрезается при скролле.

Чем интересен

  • Метаданные отдаются стримом в конце документа, а og:*, twitter:* и canonical отсутствуют полностью: превью в соцсетях формировать нечем, зато есть meta keywords.
  • Страница прокручивается не нативно: контейнер фиксирован (100vh, overflow: hidden), содержимое двигается трансформом, у body отключён скролл; на ширине 1023 px и меньше всё превращается в обычный поток документа.
  • Отрывной билет собран без единой картинки: перфорация — это пунктирная CSS-рамка, разрез имитируют два SVG-лезвия ножниц с поворотом на ±20 градусов и отдельная «молния».
  • Заголовок и счётчики «N of 3» скрыты до выполнения JS (opacity: 0, печать посимвольно), поэтому без JavaScript пользователь видит пустые блоки; cookie-баннер тоже рендерится только на клиенте.
  • Тяжёлых библиотек нет: ноль совпадений gsap, three, lottie, framer-motion и tailwind; анимация собрана из CSS-модулей и PNG-спрайта на 29 кадров, звук — из двух коротких MP3.

Технологии с доказательствами

  • Next.js (App Router, RSC) — заголовок x-powered-by: Next.js, чанки /_next/static/chunks/app/page-*.js, RSC-пейлоад self.__next_f.push
  • React 19 (стриминг метаданных) — title и description приходят не в <head>, а в конце <body> и завершаются маркером self.__next_f.push([1,"d:\"$8:metadata\""])
  • CSS Modules — хешированные классы ticket_ticket__d_kvJ, FeatureCard_wrapper__qwb3w; в 37 735 символах CSS ноль совпадений tailwind и --tw-
  • next/font, самохостинг шрифтов — @font-face с src /_next/static/media/*.woff2: 7 начертаний Inter и 8 Red Hat Mono, preload в заголовках
  • next/image — <img data-nimg="1" src="/_next/image?url=…&w=1920&q=75"> с srcSet
  • Embla Carousel — классы Reviews_embla__9yLXa и девять упоминаний embla в JS-бандле
  • Web Audio API — createBufferSource и decodeAudioData, файлы /landing/hover.mp3 (972 Б) и /landing/click.mp3 (5 374 Б)
  • Google Analytics 4 — googletagmanager.com/gtag/js?id=G-M53918BGEB и gtag('config', 'G-M53918BGEB')
  • Cloudflare — заголовки Server: cloudflare, CF-RAY, cookie __cf_bm, обфускация почты через /cdn-cgi/l/email-protection
  • DigitalOcean App Platform — заголовки x-do-app-origin и x-do-orig-status: 200
