https://basement.studio/basketball

Что это

Сайт аргентинской студии дизайна и разработки, по разделам которого перемещаешься как по смоделированному в 3D офису. Внутри есть мини-игра в баскетбол с броском мышью, счётчиком и таблицей рекордов. Необычный игровой сайт студии, перемещение по которому показано как прогулка по офису. На главном экране интерактивная игра в баскетбол, где нужно забросить мяч в кольцо мышью.

Что смотреть в первую очередь

Смотреть как пример сайта-пространства: навигация, портфолио и игра собраны в одной 3D-сцене, а не разложены по страницам.

Чем интересен

  1. Запись — про страницу /basketball внутри большого сайта студии: на ней живут общая навигация из шести разделов и глобальный футер, и она включена в sitemap.
  2. Перемещение по сайту сделано как прогулка по 3D-офису: конфигурации камеры для каждого раздела лежат прямо в данных страницы.
  3. Освещение запечено: больше 20 .exr-лайтмапов с AO-картами и явной привязкой к именам мешей — сцена не считает свет в реальном времени.
  4. Внутри сцены разложены коллекционные 3D-предметы с настоящими метаданными проектов, то есть сама сцена работает портфолио.
  5. Под игру собран отдельный звуковой набор из десятков файлов, включая стрик и тему сайта; есть режим MACHINE — текстовые версии страниц для машин (/ai/home, /ai/services).
