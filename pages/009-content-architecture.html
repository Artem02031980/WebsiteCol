Что это

Лендинг набора исходников для сборки сайтов на Next.js и Astro с headless-CMS Sanity; продаётся двумя редакциями за 549 €. Главный визуальный аттракцион — интерактивная спираль из повторяющегося названия и ASCII-превью кейсов. Шикарно оформленный сайт готового набора для разработки сайтов на Next.js или Astro с CMS Sanity. Очень оригинальные интерактивные шейдеры с текстом.

Что смотреть в первую очередь

Смотреть как пример интерактивной графики с текстом: спираль собрана на WebGL2 собственными шейдерами поверх текстового атласа, а не библиотекой эффектов. Отдельно поучительна «агентная» часть — Markdown по тому же адресу, llms.txt, openapi.json и правила для AI-краулеров.

Чем интересен

  1. Спираль из повторяющегося текста — не готовая библиотека эффектов и не Canvas 2D: текст сначала рисуется в offscreen-canvas и уходит в GPU-текстуру, а затем выводится instanced-квадами по 30 кольцам собственными шейдерами на WebGL2.
  2. Сцена действительно интерактивна: удержание кнопки заряжает кольца с глитчем и дрожанием, отпускание запускает волну, а курсор растворяет буквы в точки, подменяя индекс глифа на индекс точки в атласе.
  3. Сайт сделан «читаемым для агентов» и это проверяется машинно: каждая страница отдаёт облегчённый Markdown по тому же адресу при заголовке Accept: text/markdown, рядом лежат llms.txt и openapi.json с описанием публичной поверхности.
  4. В robots.txt есть директива Content-Signal (search=yes, ai-train=no, use-reference) и раздельные правила: поисковым краулерам разрешено, обучающим запрещено — с комментарием, что политика объявлена в кодовой базе, а не у хостера.
  5. Вся растровая графика на странице заменена ASCII: 13 canvas с ролью img и aria-label для карточек кейсов и аватаров отзывов, плюс полноэкранный ASCII-занавес перехода между страницами.
  6. Заявление продукта о React Compiler подтверждается на самом сайте: в собранных чанках 114 вхождений служебных меток компилятора.
  7. Ссылка «Imprint» в подвале ведёт на несуществующую страницу — 404; в sitemap её тоже нет.

Технологии с доказательствами

  • Next.js 16.3.4 (App Router) — в чанке window.next={version:"16.3.4",appDir:!0}, заголовки X-Nextjs-Stale-Time и Vary с rsc, рантайм Turbopack
  • React Compiler — 114 вхождений react.memo_cache_sentinel в 13 чанках — кодогенерация memo-cache, то есть сборка прошла через компилятор
  • Sanity (headless CMS) и Live Content API — компоненты SanityLink, SanityLive, SanityMuxVideo, SanityRichText; картинки с cdn.sanity.io (project szlvuc1t)
  • Tailwind CSS v4 — 555 вхождений --tw-*, 67 @property, 88 вызовов color-mix(in oklab) в собранном CSS
  • OGL (минималистичная WebGL-библиотека) — в чанке классы Renderer, Program, Geometry, Texture, вызовы createVertexArray и uniformMatrix, new Renderer({webgl:2, antialias:false})
  • WebGL2 и собственные GLSL ES 3.00 шейдеры — два шейдера с "#version 300 es": вершинный с атрибутами aRadius/aTheta0/aSpeed/aSize/aCharIdx/aRingIdx и uniform-массивами uRingCharge[30], uRippleStarts[16], фрагментный с выборкой из атласа sampler2D tAtlas
  • Canvas 2D для ASCII-графики — getContext("2d"), fillText и drawImage в чанках ASCII-занавеса и компонента AsciiImage; набор глифов ".:-=+*#%@"
  • Motion (framer-motion) — AnimatePresence, MotionConfig, useScroll, useTransform, whileInView, staggerChildren в нескольких чанках
  • Lenis — хук useLenis в семи чанках, скорость скролла передаётся в сцену спирали
  • Mux и SanityMuxVideo — компонент с пропсами video, objectFit, autoPlay, priority
  • Vercel — заголовки Server: Vercel, X-Vercel-Cache: HIT, атрибут data-dpl-id на html
  • Geist Sans и Geist Mono — @font-face для переменных GeistSans и GeistMono, preload через Link, токены --font-geist-sans и --font-geist-mono
  • Stripe — openapi.json описывает GET /api/checkout/status с session_id вида cs_live_/cs_test_; политика называет Stripe обработчиком платежей
  • Umami Cloud — next/script с cloud.umami.is/script.js, data-website-id и strategy=lazyOnload; аналитика без cookie
