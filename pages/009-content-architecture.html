Что это

Лендинг набора исходников для сборки сайтов на Next.js и Astro с headless-CMS Sanity; продаётся двумя редакциями за 549 €. Главный визуальный аттракцион — интерактивная спираль из повторяющегося названия и ASCII-превью кейсов. Шикарно оформленный сайт готового набора для разработки сайтов на Next.js или Astro с CMS Sanity. Очень оригинальные интерактивные шейдеры с текстом.

Что смотреть в первую очередь

Смотреть как пример интерактивной графики с текстом: спираль собрана на WebGL2 собственными шейдерами поверх текстового атласа, а не библиотекой эффектов. Отдельно поучительна «агентная» часть — Markdown по тому же адресу, llms.txt, openapi.json и правила для AI-краулеров.

Чем интересен

  1. Спираль из повторяющегося текста сделана не готовой библиотекой и не обычным холстом: текст сначала рисуется в скрытом холсте, затем уходит на видеокарту текстурой и выводится тридцатью кольцами собственными шейдерами — маленькими программами для видеокарты.
  2. Сцена действительно интерактивна: удержание кнопки заряжает кольца с дрожанием, отпускание запускает волну, а курсор растворяет буквы в точки.
  3. Сайт сделан «читаемым для агентов», и это проверяется машинно: любая страница отдаёт упрощённый Markdown, если запросить её с заголовком Accept: text/markdown, а рядом лежат llms.txt и описание API в openapi.json.
  4. В robots.txt объявлена политика использования контента: поисковым роботам можно, обучению ИИ — нельзя. Это редкий для сайтов случай, когда правило прописано явно и с комментарием.
  5. Вся растровая графика заменена ASCII-рисунками: тринадцать холстов с подписями для программ чтения с экрана, плюс полноэкранная ASCII-«занавесь» при переходе между страницами.
  6. Заявление продукта про React Compiler подтверждается на самом сайте: в собранных файлах 114 служебных меток компилятора.
  7. Ссылка «Imprint» в подвале ведёт на несуществующую страницу — 404, и в карте сайта её тоже нет.
