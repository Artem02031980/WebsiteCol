Что это

Сервис обратной связи для прототипов: коллеги открывают работающий прототип и кликают прямо по элементам интерфейса — оставляют комментарии, записывают видео, отвечают на вопросы. Из этого собирается список следующих шагов для ИИ-агента. Для продуктовых команд, дизайнеров и разработчиков. Свежий информативный сайт сервиса для сбора обратной связи прямо в работающем прототипе сайта или интерфейса.

Что смотреть в первую очередь

Смотреть первый экран с видео-демо и панелью активности, затем страницу MCP: она написана как инструкция ИИ-агенту. Отдельно интересен приём с markdown-версиями страниц и llms.txt.

Интересные факты

  1. Скриншот владельца — более ранняя версия: первый экран тёмный, в меню только Pricing, MCP, FAQs и Log in; живая главная по коду сейчас светлая (фон #ffffff), а в меню разметки уже есть Home, About и Sign up.
  2. У каждой страницы есть текстовая версия в формате Markdown (index.md, pricing.md, mcp.md, faqs.md, about.md), а в корне — llms.txt и llms-full.txt: так ИИ-помощники и поисковые роботы читают сайт без браузера, скриптов и вёрстки.
  3. robots.txt не закрывает сайт от ИИ, а наоборот разрешает: десятки ботов вроде GPTBot и ClaudeBot перечислены с Allow, плюс строка Content-Signal: search=yes, ai-input=yes.
  4. Страница MCP написана как инструкция для ИИ-агента: адрес сервера, команды установки для Claude Code, Codex и Cursor и правила, как не сломать уже настроенное. MCP — общий протокол, через который ИИ-помощник подключается к внешнему сервису.
  5. Сайт показывает собственный продукт: в шапку страницы вставлен их же виджет widget.js с номером рабочего пространства — тот самый слой обратной связи, который они продают.
  6. Тёмная тема осталась только для кабинета и страницы /trust, а маркетинговые страницы скрипт theme-boot.js переключает на светлую ещё до отрисовки, чтобы не было тёмной вспышки.
  7. Сайт закрыт Cloudflare: браузер получает проверку «Один момент…», а скриптовый запрос — 403; поэтому текст читался через релей translate.goog и markdown-версии, sitemap.xml из этой сети тоже 403, хотя robots.txt на него ссылается.
